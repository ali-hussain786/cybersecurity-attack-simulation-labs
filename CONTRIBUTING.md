# Contributing to CyberLab

Thank you for contributing to the Cybersecurity Attack Simulation Labs project.

## Development Workflow

1. Create a new branch for your work.
2. Make changes only inside the controlled laboratory environment.
3. Test the affected component locally.
4. Verify that existing functionality still works.
5. Use clear commit messages.
6. Submit your changes for review.

## Commit Convention

Use Conventional Commits:

```text
feat: add new security lab
fix: resolve dashboard status issue
docs: update project documentation
refactor: improve backend structure
test: add API tests
chore: update dependencies
