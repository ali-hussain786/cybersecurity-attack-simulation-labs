# Security Policy

## Purpose

Cybersecurity Attack Simulation Labs is designed for authorized security education, research, testing, and controlled laboratory environments.

## Supported Environment

The project should be used in an isolated environment such as:

- Local Docker networks
- Dedicated virtual machines
- Test containers
- Authorized academic laboratories

## Important Safety Requirements

- Do not run simulations against systems you do not own or have explicit permission to test.
- Do not expose the Docker control API or backend directly to the public internet.
- Keep destructive simulations inside isolated test environments.
- Never use real confidential, personal, or production data as simulation targets.
- Review Docker permissions carefully before running the platform.

## Reporting a Security Issue

If you discover a security issue in this project, document:

1. The affected component
2. Steps required to reproduce the issue
3. Expected behavior
4. Actual behavior
5. Relevant logs or screenshots

Do not publicly disclose sensitive details before the issue has been reviewed.

## Responsible Use

This project is intended strictly for defensive cybersecurity education, authorized research, and controlled simulations.
