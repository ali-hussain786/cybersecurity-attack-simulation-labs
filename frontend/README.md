# CyberLab Frontend

React + Vite SOC dashboard for the Cybersecurity Attack Simulation Labs platform.

## Features

- Operations dashboard and lab status
- Network discovery and victim selection
- Selected-port scanner
- Controlled ransomware simulation controls
- File-state view and recovery workflow
- Victim desktop access
- Attacker and victim logs
- Reports and evidence views
- Responsive dark cybersecurity UI

The Browser Activity Lab, Browser Activity Monitor, Browser Event History and dedicated browser telemetry test page have been removed.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:5173>. The API base URL can be configured with `VITE_API_BASE_URL`; the default is `http://localhost:5000/api`.
